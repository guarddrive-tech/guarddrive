# Product Overview

Visão de produto derivada de `docs/architecture/PRODUCT_CANON.md` — para
detalhe completo (o que é, problema, cliente, arquitetura oficial),
consulte o canon diretamente. Este documento existe apenas como resumo de
orientação rápida para quem chega pela pasta `docs/product/`.

GuardDrive vende confiança operacional para mobilidade B2B: evidência
confiável sobre eventos de frota e sinistro, entregue por uma landing
pública de qualificação, um portal de descoberta comercial interno e uma
API serverless sobre Netlify + Drizzle + Postgres. Ver
`docs/architecture/SYSTEM_BOUNDARIES.md` para o que o produto explicitamente
não é em comunicação pública.
